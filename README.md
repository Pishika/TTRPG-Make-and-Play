# TTRPG-Make-and-Play
TTRPG Make&Play — Спецификация и план проекта
1. Общее описание
TTRPG Make&Play — это десктопное приложение для ПК (ОС Windows), предназначенное для организации и проведения настольных ролевых игр (НРИ). Продукт решает проблему ручной организации разрозненной информации, объединяя в себе инструменты для создания персонажей, ведения записей и синхронизации данных между участниками игры. Проект выполняется в рамках индивидуальной исследовательской работы (ИВР) в Лицее НИУ ВШЭ.

2. Проблемное поле
Среди многих игроков и мастеров homebrew-кампаний, а также тех, кто только хочет начать играть или вести игру, существует проблема с созданием и редактированием механик, чарников (листов персонажа) и других материалов. Это занимает несколько часов работы, из которых большая часть уходит не на творчество, а на ручную организацию информации. Текущие инструменты (текстовые редакторы, таблицы) не позволяют автоматизировать процесс и требуют постоянной ручной синхронизации данных между участниками.

3. Целевая аудитория
Игроки и мастера НРИ, играющие в homebrew-кампании. Вторичная аудитория — те, кто только планирует начать играть и ищет удобный инструмент для организации игрового процесса.

4. Ключевые функции
Для всех пользователей (игроков):
- Авторизация пользователя (регистрация, вход, смена пароля, работа с сервером).
- Создание групп игроков и мастеров.
- Обмен данными с другими пользователями через приложение (картинки, чарники, текст, файлы).
- Редактирование чарников (листов персонажа).
- Экспорт/импорт данных и создание резервных копий.
- Встроенный рандомайзер с модификаторами.
- Поиск данных по доступной базе данных.
- Для мастеров (помимо всего вышесказанного):
- Создание кастомных чарников (включая импорт изображений и PDF-файлов).
- Создание и редактирование homebrew-механик, предметов и мобов.
- Управление правами доступа игроков.

5. Видение продукта и механики (Ключевой раздел)
5.1. Интерактивный лист персонажа
В отличие от статичных PDF или таблиц, лист персонажа в TTRPG Make&Play — это интерактивная среда. Игроки по умолчанию видят только свои чарники. Лист позволяет автоматически рассчитывать производные характеристики на основе введенных значений (Сила, Ловкость, Телосложение и т.д.), что избавляет от ручных вычислений.

5.2. Скриптуемые механики (Движок формул)
Центральная особенность приложения — это движок, позволяющий мастерам создавать полностью кастомные и скриптуемые механики. Это не просто текстовые описания, а исполняемые формулы, которые автоматически применяются к персонажам.
Примеры из пользовательской системы (D&D-подобная система):
- Запас HP: У огров макс HP = (Тел + 4) × 8
- Прочность тела: (Стк / 7) + (1d4) / 2 + 1
- Скорость: (Лвк / 3) + (Сил / 10) + 1
- Регенерация маны: (Инт + 4) × 100
- Урон от кровотечения на N-й тик: ур.кров. – ⌊((√(8N–7) + 1) / 2)⌋ + 1

5.3. Работа с медиафайлами
Приложение поддерживает загрузку изображений для визуализации игрового процесса: карты мира, портреты персонажей, иллюстрации предметов. Эти файлы прикрепляются к соответствующим сущностям (чарникам, механикам) и хранятся на сервере.

6. Техническая архитектура
Приложение строится по клиент-серверной архитектуре.
Клиент (Frontend): Приложение для Windows на Python (планируется PySide6 или CustomTkinter). Отвечает за интерфейс, визуализацию интерактивных листов и локальную валидацию.
Сервер (Backend): Python + FastAPI (или Flask). Отвечает за бизнес-логику, проверку прав доступа и синхронизацию данных.
База данных: PostgreSQL или SQLite. Хранит пользователей, чарники, группы, механики и медиафайлы.

Нехватка времени из-за недооценки сложности технологий: Разработка ведется по принципу MVP. Приоритизация задач: сначала самые важные функции, косметические — в последнюю очередь.
Технические сложности при связке клиентской и серверной частей: Поэтапное изучение технологий, консультации с научным руководителем и IT-специалистами.
Потеря данных или кода из-за сбоев оборудования: Регулярное использование системы контроля версий Git, резервное копирование базы данных.

10. Взаимодействие и ресурсы
Взаимодействие: с целевой аудиторией (сбор фидбека), IT-специалистами (консультации по серверной части), дизайнерами (помощь с UI/UX) и научным руководителем.
Ресурсы: личный ПК с Windows 10/11, доступ к интернету, база из нескольких homebrew TTRPG для тестирования, обучающие материалы, фокус-группа (1-2 мастера и 2-6 игроков). Временные затраты: около 7 часов в неделю.
